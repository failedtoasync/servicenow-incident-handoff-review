# Incident Handoff Review Dashboard

The Incident Handoff Review Dashboard provides an overview of review statuses, outcomes, handoff trends, and overdue reviews. It helps users monitor reviews requiring attention and assess review activity.

The dashboard includes five visualizations:

- **IHR Status Overview** — distribution of reviews by status.
- **Reviews Requiring Attention** — reviews in Pending or Under Review.
- **IHRs by Review Outcome** — Complete, Escalated, and Cancelled reviews.
- **IHRs by Handoff Count** — distribution of reviews by handoff count.
- **IHR Aging / Overdue Reviews** — aging of Pending and Under Review records, using thresholds of one day and two days respectively.
